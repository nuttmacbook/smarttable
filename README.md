# ระบบจัดตารางเรียนตารางสอน (ศธ.02 / สอศ.)

เว็บแอปจัดตารางเรียนตารางสอนสำหรับสถานศึกษาอาชีวศึกษา (สอศ.) ตรวจการชนของ **ครู กลุ่มเรียน ห้องเรียน คาบ และชั่วโมงที่ต้องเรียน** ตั้งแต่ตอนลงตาราง
หน้าเว็บเขียนด้วย HTML/CSS/JavaScript (ES modules) ข้อมูลเก็บบนเซิร์ฟเวอร์ผ่าน `api/` (Vercel + Upstash) แอดมินล็อกอินเพื่อแก้ไข ผู้ชมทั่วไปดูได้แบบอ่านอย่างเดียว

## ผู้ใช้งาน
- **แอดมิน** — เข้าสู่ระบบที่ `/#/login` แก้ไขทุกอย่างได้
- **ผู้ชมทั่วไป** — เปิดเว็บแล้วดูตารางได้ทันทีเมื่อแอดมินเปิดโหมดสาธารณะ (ชื่อครูซ่อนไว้เป็นค่าเริ่มต้น)
- **ผู้ดูผ่านลิงก์** — เปิด `…/#/view/<โทเค็น>` เห็นเฉพาะขอบเขตของลิงก์

## Build
```bash
npm ci
npm run build      # สร้าง dist/ (Vite)
```
หน้าเว็บต้องทำงานคู่กับ `api/` เสมอ (ไม่มีโหมดเก็บข้อมูลในเครื่อง) ดูวิธีรันและ deploy ที่ [`docs/DEPLOY.md`](docs/DEPLOY.md)

รองรับหน้าจอตั้งแต่ ~768px ขึ้นไป (คอมพิวเตอร์/แท็บเล็ต)

## โครงสร้าง (ส่วนหน้าเว็บ)
```
index.html                  หน้าหลัก
css/style.css               สไตล์
js/app.js                   ต่อ DOM จริงเข้ากับ app-core
js/app-core.js              ตรวจสิทธิ์ (แอดมิน/สาธารณะ/ผู้ดูลิงก์) router แถบสถานะ
js/api-client.js            เรียก api/ (CSRF header, X-Share-Token, จัดการ 401/409/422/429/ออฟไลน์)
js/pages/*.js               แต่ละหน้า (จัดตาราง รายวิชา กลุ่มเรียน แผน ห้อง ครู ข้อมูล ส่งออก ลิงก์แชร์ ตั้งค่า สาธารณะ ล็อกอิน)
js/pages/list-kit.js        ค้นหา/ตัวกรอง/แบ่งหน้า ใช้ทุกรายการ
js/pages/multi-*.js         โหมดเลือกหลายช่อง
js/export/**                ส่งออก Excel/PDF
```
