## 1. ผู้ใช้แต่ละแบบ

| ผู้ใช้ | เข้าอย่างไร | ทำอะไรได้ |
|---|---|---|
| **แอดมิน** | หน้าแรก → ลิงก์ "เข้าสู่ระบบแอดมิน" (ท้ายหน้า) แล้วกรอกชื่อผู้ใช้/รหัสผ่าน | แก้ไขได้ทุกอย่าง นำเข้า/ส่งออก ตั้งค่า จัดการลิงก์แชร์ |
| **ผู้ชมทั่วไป** | เปิดเว็บโดยไม่ต้องล็อกอิน (เมื่อแอดมินเปิดโหมดสาธารณะ) | เลือกกลุ่มเรียน/ห้องเรียน (และครู ถ้าแอดมินอนุญาต) ดูตาราง พิมพ์ ส่งออก — ไม่มีปุ่มแก้ไข |
| **ผู้ดูผ่านลิงก์** | เปิดลิงก์ที่แอดมินส่งให้ (ขึ้นต้น `…/#/view/…`) | ดูได้เฉพาะขอบเขตของลิงก์ (เช่น กลุ่มเรียนเดียว) พิมพ์/ส่งออกได้ |

ผู้ชมทุกแบบแก้ตารางไม่ได้ แม้พยายามเรียกผ่านเครื่องมืออื่น เซิร์ฟเวอร์ปฏิเสธการแก้ไขทั้งหมด

## 2. เข้าสู่ระบบ

1. เปิดเว็บ แล้วกด **"เข้าสู่ระบบแอดมิน"** ที่ท้ายหน้า (หรือเปิด `…/#/login` โดยตรง)
2. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** แล้วกด **เข้าสู่ระบบ**
3. เมื่อเข้าแล้ว แถบด้านบนแสดง "แอดมิน: ชื่อผู้ใช้", สถานะการบันทึก ("บันทึกแล้ว" / "กำลังบันทึก…" / "ออฟไลน์" / "บันทึกไม่สำเร็จ" / "มีผู้แก้ไขพร้อมกัน") และปุ่ม **ออกจากระบบ**

ข้อความที่อาจเห็นตอนเข้าสู่ระบบ:

| ข้อความ | สาเหตุ / วิธีแก้ |
|---|---|
| กรุณากรอกชื่อผู้ใช้และรหัสผ่าน | ยังกรอกไม่ครบ |
| ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง | ระบบไม่บอกว่าผิดที่ชื่อหรือรหัสผ่าน เพื่อความปลอดภัย |
| ลองเข้าสู่ระบบบ่อยเกินไป โปรดรอสักครู่แล้วลองใหม่ภายหลัง | ใส่ผิดหลายครั้งติดกัน ให้รอสักครู่ |
| เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ ลองใหม่อีกครั้ง | อินเทอร์เน็ตหลุดหรือเซิร์ฟเวอร์ไม่ตอบ |
| เซิร์ฟเวอร์ขัดข้อง ลองใหม่ภายหลัง | ปัญหาฝั่งเซิร์ฟเวอร์ |

เมื่อใช้เสร็จให้กด **ออกจากระบบ** โดยเฉพาะบนเครื่องที่ใช้ร่วมกัน ระบบจะล้างข้อมูลแอดมินออกจากหน้าจอและกลับไปหน้าสาธารณะ

## 3. ตั้งค่าเริ่มต้น (ลำดับที่แนะนำ)

เมนูของแอดมิน: **จัดตาราง · รายวิชา · กลุ่มเรียน · แผนการเรียน · ห้องเรียน · ครู · ตารางรายกลุ่มเรียน · ตารางรายครู · ตารางรายห้องเรียน · ส่งออก/พิมพ์ · ข้อมูล · ลิงก์แชร์ · ตั้งค่า**

ควรกรอกข้อมูลตามลำดับนี้ เพราะข้อมูลหลังอ้างอิงข้อมูลก่อนหน้า (หรือใช้ [นำเข้าจาก Excel](#4-นำเข้าจาก-excel) ทีเดียว):

1. **ครู** — ชื่อครู และแผนก/สาขา
2. **ห้องเรียน** — ชื่อห้อง อาคาร ความจุ (ไม่บังคับระบุห้องตอนลงตาราง)
3. **รายวิชา** — รหัสวิชา ชื่อวิชา ประเภท (สามัญ / วิชาชีพ) ชั่วโมง **ท** (ทฤษฎี) และ **ป** (ปฏิบัติ) โดย **ชม./สัปดาห์ = ท + ป**, **ระดับที่เปิดสอน** (เลือกได้หลายระดับ: ปวช.1–3, ปวส.1–2) และ **ครูผู้สอน** (0 คนขึ้นไป)
4. **แผนการเรียน** — ชื่อแผน (ห้ามซ้ำ) ระดับ และเลือกวิชาที่เปิดสอนในระดับนั้น
5. **กลุ่มเรียน** — ชื่อกลุ่ม (เช่น ปวช.1/1) ระดับ สาขา แล้วกดปุ่ม **"เลือกแผนการเรียน"** ของกลุ่ม → เลือกแผน (เฉพาะแผนที่ระดับตรงกัน) และวิธีผูก **"แทนที่"** หรือ **"เพิ่มเข้าไป"** → ดูตัวอย่างวิชาที่จะผูก/ที่ถูกข้าม → ยืนยัน (ไม่ลบคาบที่ลงตารางไว้แล้ว)

ข้อควรรู้:
- **ชม./สัปดาห์** คือจำนวนคาบที่ต้องเรียนต่อสัปดาห์ **ต่อหนึ่งกลุ่มเรียน** ลงเกินไม่ได้
- ลด ชม./สัปดาห์ ของวิชาให้ต่ำกว่าที่ลงตารางไว้แล้วไม่ได้ ต้องลบคาบที่เกินก่อน
- ถ้าลบครู ห้อง กลุ่ม วิชา หรือแผน ระบบจะแจ้งผลกระทบก่อน และลบคาบที่อ้างถึงสิ่งนั้นให้ ไม่ทิ้งข้อมูลค้าง
- คาบเรียนคาบละ 1 ชั่วโมง 11 คาบ/วัน (08:00–20:00) จันทร์–ศุกร์ พักเที่ยง 12:00–13:00 ไม่ใช่คาบเรียน

## 4. นำเข้าจาก Excel

เมนู **ข้อมูล** → การ์ด **"นำเข้าจาก Excel (.xlsx)"**

### ขั้นตอน
1. กด **ดาวน์โหลดเทมเพลต** แล้วกรอกข้อมูลตามหัวคอลัมน์ (ห้ามเปลี่ยนชื่อชีตและหัวคอลัมน์)
2. กด **เลือกไฟล์ .xlsx…** หรือลากไฟล์มาวางในกรอบ (ขนาดไม่เกิน 5 MB, ไม่เกิน 5,000 แถวต่อชีต)
3. ระบบแสดง **รายงานก่อนนำเข้า**: จำนวน ผิดพลาด / เตือน / ข้อมูล, ตารางสรุปต่อชีต (เพิ่ม / อัปเดต / ข้าม) และรายการแถวที่มีปัญหา (ค้นหา กรองระดับ และแบ่งหน้าได้) — กด **ดาวน์โหลดรายงาน** เพื่อเก็บไว้ได้
4. ถ้าไม่มีข้อผิดพลาด กด **ยืนยันนำเข้า**

### ชีตที่รองรับ
**รายวิชา · ครูผู้สอน · ห้องเรียน · กลุ่มเรียน · แผนการเรียน** (ชีตที่ไม่มีในไฟล์จะถูกข้าม แต่ต้องมีอย่างน้อย 1 ชีต)

| ชีต | คอลัมน์ |
|---|---|
| รายวิชา | รหัสวิชา · ชื่อวิชา · ประเภท · ท · ป · ชม./สัปดาห์ · หน่วยกิต · ระดับที่เปิดสอน · ครูผู้สอน · หมายเหตุ |
| ครูผู้สอน | ชื่อครู · แผนก/สาขา |
| ห้องเรียน | ชื่อห้องเรียน · อาคาร · ความจุ · หมายเหตุ |
| กลุ่มเรียน | ชื่อกลุ่มเรียน · ระดับ · สาขา · แผนการเรียน · รหัสวิชา |
| แผนการเรียน | ชื่อแผน · ระดับ · รหัสวิชา · หมายเหตุ |

### กติกาการรวมข้อมูล
- **รวมกับข้อมูลเดิม ไม่ลบอะไร**: จับคู่ตามรหัสวิชา/ชื่อ — ตรงกัน = อัปเดตเฉพาะช่องที่กรอก (ช่องว่าง = ไม่ทับค่าเดิม) ไม่ตรง = เพิ่มใหม่
- **ทั้งหมดหรือไม่เลย**: ถ้ามีข้อผิดพลาดแม้แถวเดียว จะไม่นำเข้าอะไรเลย แก้ไฟล์แล้วนำเข้าใหม่
- "ประเภท" ใช้คำว่า **สามัญ** หรือ **วิชาชีพ** · "ระดับ" ใช้ **ปวช.1, ปวช.2, ปวช.3, ปวส.1, ปวส.2**

### ข้อผิดพลาดที่พบบ่อย (ข้อความจริงในรายงาน)

| ข้อความในรายงาน | วิธีแก้ |
|---|---|
| รองรับเฉพาะไฟล์ .xlsx เท่านั้น | บันทึกไฟล์เป็น Excel Workbook (.xlsx) ไม่ใช่ .xls หรือ .csv |
| ไฟล์ใหญ่เกิน 5 MB | ตัดข้อมูลที่ไม่ใช่ออก หรือแบ่งเป็นหลายไฟล์ |
| ไม่พบชีตที่ระบบรู้จักในไฟล์ (ต้องมีอย่างน้อย 1 ชีตจาก: …) | ชื่อชีตต้องตรงกับเทมเพลตเป๊ะ |
| ไม่พบคอลัมน์ "…" ในชีต "…" | หัวคอลัมน์ขาดหรือสะกดต่างจากเทมเพลต |
| หัวคอลัมน์ "…" ซ้ำ | มีหัวคอลัมน์ชื่อเดียวกันสองช่อง ให้ลบอันหนึ่ง |
| ต้องระบุ "ชื่อครู" / "ชื่อห้องเรียน" / "ชื่อกลุ่มเรียน" / "ชื่อแผน" / "รหัสวิชา" | แถวนั้นไม่มีค่าในคอลัมน์หลัก |
| รหัสวิชา "…" ซ้ำในไฟล์ (ซ้ำกับแถว N) | รหัสวิชาต้องไม่ซ้ำกันในชีตเดียวกัน |
| ต้องระบุ "ชื่อวิชา" สำหรับวิชาใหม่ | วิชาที่ยังไม่มีในระบบต้องกรอกครบ |
| "ประเภท" ต้องเป็น สามัญ หรือ วิชาชีพ (พบ "…") | พิมพ์ผิดหรือใช้คำอื่น |
| "ชม./สัปดาห์" (X) ไม่เท่ากับ ท+ป (Y) | ชั่วโมงรวมต้องเท่ากับ ท + ป หรือเว้น "ชม./สัปดาห์" ไว้ให้ระบบคำนวณ |
| ท+ป ต้องรวมกันอย่างน้อย 1 ชม./สัปดาห์ | วิชาต้องมีชั่วโมงอย่างน้อย 1 |
| "…" ต้องเป็นจำนวนเต็ม ≥ N (พบ "…") | ช่องตัวเลขมีตัวอักษรหรือทศนิยม |
| ระดับ "…" ไม่ถูกต้อง (ต้องเป็น ปวช.1, ปวช.2, ปวช.3, ปวส.1, ปวส.2) | สะกดระดับให้ตรง |
| ไม่พบครู "…" (ต้องมีในชีต "ครูผู้สอน" หรือในระบบ) | ชื่อครูในชีตรายวิชาต้องตรงกับชื่อครูที่มีอยู่ |
| ไม่พบรหัสวิชา "…" (ต้องมีในชีต "รายวิชา" หรือในระบบ) | แผน/กลุ่มอ้างรหัสวิชาที่ไม่มี — เพิ่มวิชาก่อนหรือแก้รหัส |
| ไม่พบแผนการเรียน "…" (ต้องมีในชีต "แผนการเรียน" หรือในระบบ) | กลุ่มอ้างแผนที่ไม่มี |
| "…" ยาวเกิน N ตัวอักษร | ตัดข้อความให้สั้นลง |
| ชีต "…" มี N แถว เกินที่รองรับ 5000 แถว | แบ่งไฟล์ |

หมายเหตุ: ถ้าข้อผิดพลาดเป็นเรื่องชั่วโมงเกิน จะมีปุ่ม **"นำเข้าและตัดคาบส่วนเกินออก"** ให้เลือก (ระบบตัดคาบที่ลงทีหลังสุดออก และบอกจำนวนที่ตัดในข้อความยืนยัน)

## 5. จัดตาราง

เมนู **จัดตาราง** → เลือก **กลุ่มเรียน** จากช่องค้นหาด้านบน (พิมพ์ชื่อกลุ่มเพื่อค้นหาได้)

### แผงรายวิชาด้านข้าง
แสดงวิชาที่กลุ่มต้องเรียน พร้อม **ต้องเรียน / จัดแล้ว / เหลือ** และแถบความคืบหน้า วิชาที่เหลือมากอยู่ก่อน วิชาที่ครบแล้วขึ้น "เสร็จ ✓" อยู่ท้าย วิชาที่ลงเกิน (ข้อมูลเก่า) แสดง "เกิน N ชม." บนจอแคบแผงนี้เป็นลิ้นชัก เปิดด้วยปุ่ม **"รายวิชา"**

### ลงวิชาทีละช่อง
- **วิธี ก:** คลิกช่องว่างในตาราง → เลือกวิชา → เลือกครู/ห้องเรียน (ถ้ามีหลายตัวเลือก) → ยืนยัน
- **วิธี ข:** คลิกวิชาในแผงด้านข้างก่อน (ขึ้นแถบ "กำลังลง: …") แล้วคลิกช่องว่างได้ต่อเนื่อง กด **ยกเลิก** เพื่อเลิกลง
- คลิกช่องที่มีวิชาแล้วเพื่อ **เปลี่ยนครู/ห้อง**, **ย้าย** หรือ **ลบออกจากตาราง** (การย้าย: ระบบขึ้น "กำลังย้ายวิชา …" แล้วคลิกช่องว่างปลายทาง กด **ยกเลิกการย้าย** เพื่อเลิก)
- ปุ่ม **"ล้างตารางกลุ่มเรียนนี้"** ลบทุกคาบของกลุ่มที่เลือก (มีข้อความยืนยันก่อน)

สัญลักษณ์ในช่อง: **ส** = วิชาสามัญ · **ช** = วิชาชีพเฉพาะ · **ร** = เรียนรวม (วิชาเดียวกันหลายกลุ่มในคาบเดียวกัน)

### ลงและลบหลายช่อง
เปิดสวิตช์ **"โหมดเลือกหลายช่อง"** เหนือตาราง
- **เลือกช่อง:** คลิกสะสม · ลากข้ามหลายช่อง · Shift+คลิกเพื่อเลือกเป็นช่วง · บนจอทัชใช้ปุ่ม **"เลือกเป็นช่วง"** แทน Shift · กด **Esc** หรือปุ่ม **ล้างการเลือก** เพื่อยกเลิกการเลือก (เลือกได้สูงสุด 200 ช่อง)
- **ลงวิชา:** เลือกวิชา (และครู/ห้องถ้าต้องการ) → กด **"ลงตาราง (N ช่อง)"** ระบบตรวจล่วงหน้าทุกช่องก่อน
  - ถ้าลงได้ทุกช่อง → ลงทั้งชุดในครั้งเดียว
  - ถ้ามีบางช่องลงไม่ได้ → ขึ้น **"ผลการตรวจล่วงหน้า"** บอกเหตุผลรายช่อง (ชนครู / ชนห้อง / ชั่วโมงเต็ม / ระดับไม่ตรง / พักเที่ยง / ช่องซ้ำ …) แล้วเลือก **"ลงเฉพาะช่องที่ลงได้ (K จาก N)"** หรือ **"ยกเลิกทั้งชุด"** (ไม่มีการลงกึ่งกลางโดยไม่บอก)
- **ลบ:** เลือกชนิด **"ลบวิชาที่ลงแล้ว"** → เลือกช่องที่มีวิชา → กด **"ลบที่เลือก (N)"** ระบบสรุปวิชาและจำนวนคาบให้ยืนยันก่อนลบ

### กฎกันชนและข้อความที่จะเห็น
ระบบตรวจทุกครั้งที่ลงหรือย้าย ถ้าลงไม่ได้จะบอกเหตุผลเป็นภาษาไทย เช่น

| กรณี | ข้อความ (ตัวอย่างรูปแบบ) |
|---|---|
| กลุ่มเรียนมีวิชาในคาบนั้นแล้ว | กลุ่มเรียน … วัน… คาบ … มีวิชา … ลงไว้แล้ว |
| ครูสอนที่อื่นในคาบเดียวกัน | ครู… สอนวิชา … ที่กลุ่มเรียน … วัน… คาบ … อยู่แล้ว จึงสอนวิชา … ที่กลุ่มเรียน … พร้อมกันไม่ได้ |
| ห้องเรียนถูกใช้ | ห้องเรียน … ถูกใช้โดยกลุ่มเรียน … (วิชา …) อยู่แล้ว |
| ระดับไม่ตรง | วิชา … เปิดสอนระดับ … แต่กลุ่มเรียน … เป็นระดับ … |
| ชั่วโมงเต็ม | วิชา … กลุ่มเรียน … กำหนด N ชม./สัปดาห์ ลงแล้ว N คาบ ลงเพิ่มไม่ได้ (จะเกินเป็น N+1 คาบ) |
| ช่วงพักเที่ยง | ช่วงพักเที่ยง 12:00–13:00 ไม่ใช่คาบเรียน ลงวิชาไม่ได้ |

ข้อยกเว้น **เรียนรวม**: เฉพาะ **วิชาสามัญ** วิชาเดียวกัน ต่างกลุ่มเรียน ลงคาบเดียวกันได้ (ใช้ครูและห้องเดียวกันร่วมกันได้ แสดงสัญลักษณ์ **ร**) — วิชาชีพเรียนรวมข้ามกลุ่มเรียนไม่ได้

ถ้าข้อมูลเดิม (เช่น นำเข้าจากระบบเก่า) มีรายการเกินชั่วโมงหรือชนอยู่แล้ว จะมีแถบแดง **"มี N รายการเกินชั่วโมงหรือชน ต้องแก้ก่อนบันทึก"** กด **ดูรายการ** เพื่อดูรายละเอียด แล้วลบหรือย้ายคาบที่เกิน

### ดูตารางรายกลุ่ม / รายครู / รายห้อง
เมนู **ตารางรายกลุ่มเรียน / รายครู / รายห้องเรียน** — เลือกจากรายการค้นหา แล้วดูตารางอ่านอย่างเดียว พร้อมปุ่มพิมพ์

## 6. ค้นหาและแบ่งหน้า

ทุกรายการ (วิชา กลุ่มเรียน ห้องเรียน ครู แผนการเรียน ลิงก์แชร์ รายงานนำเข้า รายการส่งออก รวมถึงช่องเลือกยาว ๆ) มีแถบเดียวกัน:
- **ช่องค้นหา** พิมพ์ได้หลายคำ (เว้นวรรค) ผลกรองทันที
- **ตัวกรอง** (ถ้ามี) เช่น สถานะลิงก์ ระดับ ประเภทวิชา
- **เรียงลำดับ**
- **ขนาดหน้า** 25 / 50 / 100 รายการ และปุ่มเลื่อนหน้า พร้อมข้อความ "แสดง 1–25 จาก N" และ "หน้า X / Y"
- ช่องเลือกที่มีไม่เกิน 25 ตัวเลือกเป็นรายการเลือกธรรมดา เกินกว่านั้นเป็นช่องค้นหา

ค่าค้นหา/ตัวกรอง/ขนาดหน้าถูกจำไว้ในเบราว์เซอร์เครื่องนั้น และล้างเมื่อออกจากระบบ

## 7. พิมพ์และส่งออก PDF / Excel

เมนู **ส่งออก/พิมพ์** (ผู้ชมทั่วไปและผู้ดูผ่านลิงก์ใช้ได้ในขอบเขตที่เห็น)

1. เลือก **ประเภท**: กลุ่มเรียน / ครู / ห้องเรียน หรือ **ทุกประเภททั้งหมด**
2. เลือก **ขอบเขต**: รายการเดียว · หลายรายการ (ติ๊กเลือก) · ทั้งหมดของประเภทนี้
3. (ไม่บังคับ) ใส่ **ภาคเรียนที่** และ **ปีการศึกษา** เพื่อพิมพ์ในหัวตาราง
4. เลือกรูปแบบ **Excel (.xlsx)** หรือ **PDF (.pdf)** แล้วกด **ส่งออกไฟล์** — หรือกด **พิมพ์** เพื่อสั่งพิมพ์จากเบราว์เซอร์

ผลลัพธ์:
- **PDF:** 1 รายการ = 1 หน้า **A4 แนวนอน** ฝังฟอนต์ไทย Sarabun อ่านชัดทุกช่อง
- **Excel:** 1 รายการ = 1 ชีต ตั้งหน้ากระดาษแนวนอน หัวตารางตรึง
- ถ้าส่งออกไม่สำเร็จ ให้ใช้ปุ่ม **พิมพ์** แล้วเลือก "บันทึกเป็น PDF" แทนได้
- ตอนพิมพ์: เลือกกระดาษ A4 แนวนอน และปิดหัว/ท้ายกระดาษของเบราว์เซอร์เพื่อให้ตารางพอดีหน้า

## 8. ลิงก์ดูอย่างเดียว

เมนู **ลิงก์แชร์** (แอดมิน) — สร้างลิงก์ให้คนที่ควรเห็นตารางเฉพาะส่วน โดยไม่ต้องมีรหัสผ่าน

1. กด **+ สร้างลิงก์ใหม่**
2. ใส่ **ป้ายชื่อ** (ไว้จำว่าส่งให้ใคร ไม่ใส่ก็ได้)
3. เลือก **ขอบเขต**: ทั้งหมด · กลุ่มเรียนเดียว · ครูคนเดียว · ห้องเรียนเดียว (แล้วเลือกรายการ)
4. (ไม่บังคับ) ตั้ง **วันหมดอายุ** — ลิงก์ขอบเขต "ทั้งหมด" ถ้าไม่กรอกจะหมดอายุใน **90 วัน**
5. ระบบแสดงลิงก์เต็ม **ครั้งเดียว** ให้กด **คัดลอก** ทันที ถ้าทำหายต้อง **สร้างใหม่**

ในรายการลิงก์:
- **สร้างใหม่** — ได้ลิงก์ใหม่ขอบเขตเดิม ลิงก์เดิมใช้ไม่ได้ทันที
- **เพิกถอน** — ผู้ที่มีลิงก์เปิดดูไม่ได้ทันที
- ค้นหาตามป้ายชื่อ/ขอบเขต และกรองตามสถานะ (ใช้งานได้ / หมดอายุ) ได้

ผู้เปิดลิงก์เห็นแถบ "คุณกำลังดูตารางแบบดูอย่างเดียว (ขอบเขต: …)" ถ้าลิงก์ถูกเพิกถอน หมดอายุ หรือพิมพ์ผิด จะขึ้น **"ลิงก์นี้ใช้ไม่ได้"** โดยไม่บอกสาเหตุ

> ระวัง: ตารางจากลิงก์แชร์แสดงชื่อครู (ข้อมูลส่วนบุคคล) — ส่งลิงก์เฉพาะผู้ที่ควรเห็น

## 9. โหมดสาธารณะและการซ่อนชื่อครู (PDPA)

โหมดสาธารณะ = ใครก็เปิดเว็บแล้วดูตารางได้โดยไม่ต้องล็อกอินและไม่ต้องมีลิงก์ เมนู **ตั้งค่า** (แอดมิน) มีสวิตช์สองตัว มีผลทันที:

| สวิตช์ | ความหมาย |
|---|---|
| **เปิดโหมดสาธารณะ** | เปิด = ผู้ชมทั่วไปดูตารางได้ · ปิด = ต้องใช้ลิงก์แชร์เท่านั้น ผู้เข้าเว็บจะเห็น "ผู้ดูแลปิดการเข้าชมสาธารณะ" |
| **แสดงชื่อครูในโหมดสาธารณะ** | **ปิดไว้เป็นค่าเริ่มต้น** — ผู้ชมทั่วไปจะไม่เห็นรายชื่อครู ไม่มีมุมมองรายครู ช่องตารางไม่แสดงครู และส่งออกรายครูไม่ได้ (เซิร์ฟเวอร์ไม่ส่งข้อมูลครูไปเลย ไม่ใช่แค่ซ่อนบนหน้าจอ) |

- ชื่อครูเป็นข้อมูลส่วนบุคคล (PDPA) เปิดแสดงเมื่อได้รับอนุญาตเท่านั้น
- ตราบใดที่แอดมินยังไม่กด **บันทึกตั้งค่า** ครั้งแรก จะมีแบนเนอร์ **"ยังไม่ยืนยัน"** เตือนในทุกหน้าของแอดมิน และระบบซ่อนชื่อครูให้ไว้ก่อน
- **ข้อควรระวัง:** ระบบซ่อนเฉพาะชื่อครูที่มาจากข้อมูลครู ถ้ามีชื่อครูพิมพ์อยู่ในช่องหมายเหตุของวิชา/ห้อง/กลุ่ม ระบบลบให้ไม่ได้ กรุณาตรวจก่อนเปิดโหมดสาธารณะ
- ถ้ามีผู้ดูแลสองคนแก้ตั้งค่าพร้อมกัน จะขึ้น "มีผู้แก้ไขตั้งค่าพร้อมกัน โปรดโหลดหน้าใหม่แล้วลองอีกครั้ง"

## 10. สำรองและกู้คืนข้อมูล

เมนู **ข้อมูล**

- **ส่งออก JSON** — ดาวน์โหลดข้อมูลทั้งระบบเป็นไฟล์ `timetable-ปปปป-ดด-วว.json` ควรทำเป็นประจำ (เช่น ก่อนและหลังจัดตารางใหญ่ ก่อนปิดภาคเรียน)
- **นำเข้า JSON…** — กู้คืนจากไฟล์ที่ส่งออกไว้ (รองรับไฟล์จากระบบรุ่นเก่า v1–v4 ระบบแปลงให้) ระบบตรวจโครงสร้าง การชน และชั่วโมงทั้งตารางก่อน **ถ้าไม่ผ่านจะไม่แทนที่ข้อมูลเดิม** (กรณีชั่วโมงเกินมีปุ่ม "นำเข้าและตัดคาบส่วนเกินออก")
- **ล้างข้อมูลทั้งหมด** — ลบทุกอย่าง ระบบแสดงจำนวนที่จะถูกลบและขอให้ยืนยันก่อน

ก่อนการ **นำเข้า JSON ที่แทนที่ข้อมูลเดิม** หรือ **ล้างข้อมูล** ระบบจะดาวน์โหลดไฟล์ `สำรองก่อนแทนที่-…json` ของข้อมูลปัจจุบันให้อัตโนมัติ — เก็บไฟล์นี้ไว้ ถ้าเปลี่ยนใจให้กู้คืนด้วย "นำเข้า JSON"

นอกจากนี้เซิร์ฟเวอร์เก็บประวัติเวอร์ชันของข้อมูลไว้ (ดูรายละเอียดการกู้คืนฝั่งเซิร์ฟเวอร์ในเอกสาร deploy: `docs/DEPLOY.md`) — การกู้คืนระดับนี้ทำโดยผู้ดูแลระบบเซิร์ฟเวอร์ ไม่มีปุ่มในหน้าเว็บ

## 11. คำถามที่พบบ่อย

**ลงวิชาไม่ได้ ขึ้นว่าชนครู ทำอย่างไร?**
ข้อความบอกว่าครูคนนั้นสอนกลุ่มไหนอยู่ในคาบนั้น ให้เลือกคาบอื่น เลือกครูคนอื่น (ถ้าวิชามีหลายครู) หรือย้ายคาบเดิม ถ้าตั้งใจให้หลายกลุ่มเรียนรวมกัน ต้องเป็นวิชาสามัญวิชาเดียวกัน (วิชาชีพเรียนรวมข้ามกลุ่มไม่ได้)

**ทำไมวิชานี้ไม่ขึ้นในรายการให้เลือก?**
รายการเลือกวิชาแสดงเฉพาะวิชาที่ลงได้ (ระดับตรงกับกลุ่ม และยังเหลือชั่วโมง) ในหน้าต่างเลือกวิชามีตัวเลือก **"แสดงเฉพาะวิชาที่ลงได้"** (ติ๊กไว้เป็นค่าเริ่มต้น) เอาติ๊กออกเพื่อดูวิชาที่ลงไม่ได้ด้วย

**ลงวิชาครบ ชม./สัปดาห์ แล้ว ต้องการลงเพิ่ม?**
ไม่ได้ ระบบกันไม่ให้เกิน ถ้าต้องการเพิ่มให้เพิ่ม ท/ป ของวิชาที่หน้า **รายวิชา** ก่อน

**ขึ้น "มีผู้แก้ไขพร้อมกัน" / สถานะ "มีผู้แก้ไขพร้อมกัน"?**
มีแอดมินอีกคนแก้ข้อมูลระหว่างที่คุณแก้ ระบบโหลดข้อมูลล่าสุดมาให้แล้ว ตรวจดูแล้วทำรายการซ้ำ

**สถานะ "ออฟไลน์" หรือ "บันทึกไม่สำเร็จ"?**
อินเทอร์เน็ตหลุดหรือเซิร์ฟเวอร์ตอบไม่ได้ รายการล่าสุดอาจยังไม่ถูกบันทึก ตรวจการเชื่อมต่อแล้วทำซ้ำ ข้อมูลบนหน้าจอคือข้อมูลที่เซิร์ฟเวอร์ยืนยันแล้วเท่านั้น

**ถูกออกจากระบบเอง?**
เซสชันหมดอายุ ให้เข้าสู่ระบบใหม่ ข้อมูลที่บันทึกแล้วไม่หาย

**ผู้ชมทั่วไปไม่เห็นชื่อครู?**
เป็นค่าเริ่มต้นเพื่อความเป็นส่วนตัว (PDPA) เปิดได้ที่ **ตั้งค่า → แสดงชื่อครูในโหมดสาธารณะ** ถ้าได้รับอนุญาตแล้ว

**นำเข้า Excel แล้วไม่มีอะไรเปลี่ยน?**
ถ้ามีข้อผิดพลาดแม้แถวเดียว ระบบไม่นำเข้าเลย ดูรายงานก่อนนำเข้า แก้ไฟล์ตามข้อความ แล้วนำเข้าใหม่

**ใช้บนโทรศัพท์ได้ไหม?**
ออกแบบสำหรับคอมพิวเตอร์และแท็บเล็ต (จอกว้างตั้งแต่ประมาณ 768 พิกเซล) หน้าสาธารณะสำหรับดูตารางเปิดบนจอเล็กได้แต่ตารางจะแน่น

**อยากเก็บตารางไว้เป็นไฟล์?**
ใช้เมนู **ส่งออก/พิมพ์** เลือก PDF (A4 แนวนอน) หรือ Excel
